# late_favorite

注册名是 `late_favorite`。Lua 加载器不要求 `lua_` 前缀，只要求目录名等于 `manifest.name`。

这是目前在全量历史成交回放与未使用样本外留出集上同时达到 **胜率 ≥ 80% 且盈亏比（PF）≥ 1.2** 的首选实盘候选策略（限 **BTC 5 分钟轮**）。进程的 `DRY_RUN` 默认仍是 `true`，启用它不会关掉 dry-run：

```sh
--enable-strategy late_favorite
```

> 风险提示：历史回放与 dry-run 表现不构成未来实盘收益保证。本次优化仅调整策略参数，未改动任何全局风控或账本阈值；建议先在 dry-run 观察数个交易日成交与实际滑点，再由用户自行决策是否切换 Live 或调整风控阈值。

## 策略原理与出厂参数

仅做 BTC 5 分钟轮（`btc_only = 1`、`max_round_sec = 300`）。策略通过 `bk_on_kline` 接收 Binance `BTCUSDT` 1 秒收盘 K 线（`sec1`）：

1. **轮次开盘基准**：在轮次起始边界记录该 300 秒轮的现货开盘价 `spot_open`；若程序在轮次中途启动而未见开盘价，或现货最新行情滞后超过 `max_spot_age_ms`（默认 5000 ms），**fail-closed 跳过该轮**。
2. **多尺度保守波动率**：每 10 秒采样过去 120s / 300s / 600s 对数收益率，取三者中最大的每秒波动率 `σ = max(σ120, σ300, σ600)`（避免平静期低估尾部反转风险）。
3. **Digital Black-Scholes 公允概率与成本边际**：在剩余 `20–120` 秒（`min_time_left=20`、`max_time_left=120`）、卖一价落在 `0.75–0.86`（`min_px=0.75`、`max_px=0.86`）时，计算：
   - `z = ln(spot_now / spot_open) / (σ · √(time_left + 1))`（买跌取 `ln(spot_open / spot_now)`）
   - `fair = Φ(z)`
   - `fee = 0.07 × p × (1 − p)`（自动读取内核 `bk.fees()` 费率）
   - 仅当 `fair − (p + fee) ≥ min_edge`（默认 `0.10`）且过去 `mom_window_sec = 15` 秒现货动量与所买方向同向时才入场；同一轮次同一 condition 最多入场一次，持有至结算（`bk_thesis_death` 返回 `false`）。

| 参数 | 出厂默认值 | 说明 |
|---|---:|---|
| `btc_only` | `1` | 仅做 BTC（避免多币同轮高度相关连亏） |
| `max_round_sec` | `300` | 默认仅允许 5 分钟轮（设为 0 可放开 15 分钟等实验轮） |
| `maker_entry` | `0` | 0 = taker 吃卖一（`late-taker`）；1 = post-only 挂买一（低于 `min_time_left` 撤单） |
| `min_px` / `max_px` | `0.75` / `0.86` | 入场价格区间，封顶 0.86 控制单笔亏盈倍数 |
| `min_time_left` / `max_time_left` | `20` / `120` | 距结算剩余秒数窗口（`gate_exemptions.timing_min_time_left_sec = 20`） |
| `min_edge` | `0.10` | 要求公允概率至少高出含费成本 10 个百分点 |
| `mom_window_sec` | `15` | 现货短期同向动量确认窗口（秒） |
| `max_spot_age_ms` | `5000` | 现货断流超时保护（毫秒），超时 fail-closed |

## 已经验证但未采纳的设计

- **盘中现货反转早平止损**：在验证集（10-26..11-05）上，若按保守可成交买价 `min(tape_bid, fair − 0.03)` 并计入双向 taker 手续费，在 `fair ≤ 0.50` 或 `0.35` 触发早平，PF 与净利反而从 `1.543 / +$162.1` 下降到 `1.491 / +$149.1`，因此继续持有至结算（`holds_to_settlement = true`）。
- **BTC 15 分钟轮**：在 40 天训练集（3,840 个 15m 市场）上，相同规则正常延迟下 PF 为 `1.235`（316 笔、83.54%），但在 +2s/+1¢ 压力下降至 `1.013`（仅微利），稳健度不足，默认 `max_round_sec=300` 将其隔离为实验选项。
- **多资产（ETH/SOL/XRP）同开**：加密短周期高度正相关，反转轮会同时触发多个资产连亏；默认 `btc_only=1` 锁定单标的。
